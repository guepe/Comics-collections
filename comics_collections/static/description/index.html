Comic Collection

Gérez votre collection de bandes dessinées directement dans Odoo 19.

Séries, albums, auteurs, éditeurs, wishlist, import CSV/Excel — tout ce qu'il faut pour le collectionneur exigeant.

Fonctionnalités principales

📚 Collection

  • Gérez vos séries et vos albums avec couvertures
  • Suivez les tomes possédés, en cours, terminés
  • Note 0 à 5 étoiles par album
  • État de lecture : Non lu / En cours / Lu
  • Wishlist pour les tomes à acquérir

🔍 Sources de données

  • Enrichissement depuis Google Books (ISBN ou titre)
  • Téléchargement automatique des couvertures HD
  • Détection automatique série / tome / auteurs / éditeur
  • Import de série complète en un clic
  • Sources Open Library et BnF (dépôt légal français)

📥 Import

  • Import depuis fichier CSV, XLS ou XLSX
  • Wizard 4 étapes : Upload → Mapping → Prévisualisation → Import
  • Modèle de fichier téléchargeable
  • Rapport d'erreurs détaillé

🛒 Liens d'achat

  • Liens Club.be, Amazon.be, FNAC.be générés automatiquement depuis l'ISBN
  • Ouverture en un clic dans un nouvel onglet
  • Régénération manuelle si besoin

Vues Kanban avec couvertures

Parcourez vos séries et albums sous forme de grille avec les couvertures en grand format. Un placeholder éditorial coloré est affiché automatiquement si la couverture n'est pas encore disponible. Une barre de progression indique les tomes possédés sur le total de chaque série.

Pour qui ?

Tout collectionneur de bandes dessinées souhaitant gérer sa bibliothèque depuis Odoo : suivi des séries, inventaire des albums, wishlist, auteurs, éditeurs, genres.

Compatible avec les collections BD franco-belge, manga et comics. Conçu pour Odoo 19 Community et Enterprise.
