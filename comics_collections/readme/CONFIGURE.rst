No configuration is required after installation. Genre data is loaded at install
time and a demo dataset is available in demo mode.

**Security groups** (*Settings → Users & Companies → Users*, section *Bandes Dessinées*):

- **Utilisateur** — reads and edits the shared catalogue (series, albums, editions, ISBN,
  authors, publishers); can delete only the records they created; sees only their
  own loans.
- **Gestionnaire** — full access, including deletion of any record, the
  *Configuration* menu, the advanced reference data (*Éditions*) and the
  deduplication tools.

**Scheduled actions** (*Settings → Technical → Automation → Scheduled Actions*):

- purchase links for editions with an ISBN (weekly);
- reminder activities for overdue loans (daily).
