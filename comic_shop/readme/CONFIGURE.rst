1. Install ``comic_shop`` on top of ``comics_collections`` and ``comic_datasource``.
   A *Bandes Dessinées* POS category is created at installation.
2. In **Point of Sale → Configuration → Settings**, make sure the shop's POS
   includes the *Bandes Dessinées* category.
3. Set the sale price of comic products (products are created without a price).
4. Assign managers to the *Gestionnaire* comic group: they receive the review
   activities for records created from the portal.
